# Scenario Catalog

## Purpose
This document defines how experiment scenarios are identified and described.

## Scenario ID format
Use:

- `SCN-<area>-<name>`

Examples:
- `SCN-BOOTSTRAP-LOCAL`
- `SCN-A-DIRECT-BASELINE`
- `SCN-B-GATEWAY-BASELINE`
- `SCN-WIFI-LOSS`
- `SCN-BACKEND-DOWN`

## Scenario entry template
Each scenario definition should include:
- scenario ID
- short name
- purpose
- system state or failure condition being exercised
- expected evidence to collect
- related plans or run notes

## Notes
This catalog defines scenario structure only. It does not contain results.
