# Run Procedure

## Purpose
This document defines the minimum structure for executing and recording a run.

## Run ID format
Use:

- `RUN-YYYYMMDD-HHMM-<shorttag>`

Example:
- `RUN-20260326-1615-bootstrap`

## Minimum run record
A run should capture:
- run ID
- related scenario ID
- date and time
- branch
- commit hash
- commands used
- evidence collected
- location of raw and processed outputs
- short factual notes

## Notes
Run records must stay factual and must not contain thesis conclusions.
