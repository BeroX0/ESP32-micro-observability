# Threat Model

## Purpose
This document defines the security-relevant concerns that the project must keep in view.

## Focus areas
The project pays attention to:
- exposure of observability endpoints
- unauthorized access to metrics
- over-permissioned access paths
- degraded behavior when dependencies are unavailable
- accidental leakage of local secrets or tokens

## Notes
This document identifies concern areas only. It does not claim final mitigations or conclusions.
